# billie.

Site vitrine et politique de confidentialité de **Billie**, l'appli Android pour scanner ses billets de concert, théâtre, humour, sport et festival : compte à rebours, rappels, widgets et souvenirs.

Le site est publié avec GitHub Pages depuis la branche `main`, à la racine du dépôt.

## Pages

- `index.html` : accueil
- `confidentialite.html` : politique de confidentialité (lien demandé par Google Play)
- `mentions-legales.html` : mentions légales
